# 2026-11-19 : port série avec teleplot

**Séance :** planifiée · **Durée :** 1 h 30

## Fait

Pour cette séance, on établit une liaison entre le microcontrôleur et le PC avec une liaison série, on utilise donc une voie de transmission et de réception sur les deux objets, ici juste l'USB natif de l'ESP32 donc pas de fils à croiser.  
Les codes mettent les deux éléments interactifs à la même vitesse, puis les font communiquer.  
Sur le premier code par exemple, on reçoit les données de sin.

Ensuite, on utilise teleplot pour afficher, graphiquement ou non, les données renvoyées.  
On peut utiliser l'extension comme un afficheur texte classique, ou faire des graphiques comme sur les images suivantes :
