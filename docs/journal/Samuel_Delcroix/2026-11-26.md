# 2026-11-26 : mise en place de l'écran

**Séance :** planifiée · **Durée :** 1 h 30

## Fait

Aujourd'hui, j'ai branché l'écran et fait un code afin d'afficher l'équivalent d'une page d'accueil pong

## Pourquoi

Dans le code, j'ai fait un premier essai et j'ai remarqué que les couleurs étaient inversées. Pour remédier à ce problème, j'ai trouvé deux solutions :  
- celle offerte par la documentation, soit utilisée une commande pour inverser les couleurs ;  
- j'ai aussi testé en inversant les couleurs manuellement (0xFFFF - 0xYYYY avec 0xYYYY la couleur de base)

Les deux solutions ont fonctionné et ont permis d'afficher le résultat voulu
